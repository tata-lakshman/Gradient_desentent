## 📂 Repository Contents

### 1. Gradient Descent

**Files:**

* `Gradient_desentent-1.ipynb`
* `Gradient_desencent-2.ipynb`

These notebooks focus on understanding **Gradient Descent**, an optimization algorithm used to minimize a loss or cost function.

The notebooks demonstrate the basic concepts behind iterative optimization and how model parameters can be updated to reduce error.

---

### 2. Hugging Face

**File:**

* `Hugging_Face.ipynb`

This notebook provides hands-on practice with the **Hugging Face ecosystem** and transformer-based models.

It helps understand how pretrained NLP models can be loaded and used for different Natural Language Processing tasks.

---

### 3. Extractive Question Answering

**File:**

* `Qestion_Answerring(Extractive)-1.ipynb`

This notebook demonstrates **Extractive Question Answering**, where a model identifies the answer to a question directly from a given context.

The notebook provides practical exposure to transformer-based NLP question-answering systems.

---

### 4. TensorFlow Neural Network — Regression

**File:**

* `TensorFlow(NN)_Regression.ipynb`

This notebook focuses on using **TensorFlow Neural Networks for regression problems**.

The model learns relationships between input features and a continuous target value.

Key concepts include:

* Neural network architecture
* Model training
* Loss functions
* Optimizers
* Predictions
* Regression evaluation

---

### 5. TensorFlow Neural Network — Binary Classification

**File:**

* `TensorFlow(NN)_binary_Classification.ipynb`

This notebook demonstrates **binary classification using a TensorFlow neural network**.

The model predicts one of two possible classes.

Key concepts include:

* Neural network layers
* Binary classification
* Model compilation
* Training
* Validation
* Predictions
* Classification evaluation

---

### 6. TensorFlow — Multi-Class Classification

**File:**

* `TF_MultiClass_Classification.ipynb`

This notebook demonstrates **multi-class classification using TensorFlow**.

Unlike binary classification, the model predicts one class from multiple possible categories.

The notebook provides practical experience with:

* Neural networks
* Multi-class output
* Model training
* Loss functions
* Optimizers
* Predictions
* Model evaluation

## ▶️ How to Use

Clone the repository:

```bash
git clone https://github.com/tata-lakshman/Gradient_desentent.git
```

Navigate into the repository:

```bash
cd Gradient_desentent
```

Install the commonly used libraries:

```bash
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow transformers
```

Open the notebooks using Jupyter Notebook or upload them to Google Colab.

```bash
jupyter notebook
```
